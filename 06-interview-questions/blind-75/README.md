#### 1. Two Sum

**Problem**: Find two numbers that add up to target.

**Link**: [LeetCode #1](https://leetcode.com/problems/two-sum/)

**Difficulty**: Easy

**Solution**:

```python
def two_sum(nums: list[int], target: int) -> list[int]:
    """
    Approach: Hash map to store complements
    
    Time: O(n)
    Space: O(n)
    """
    seen = {}
    
    for i, num in enumerate(nums):
        complement = target - num
        
        if complement in seen:
            return [seen[complement], i]
        
        seen[num] = i
    
    return []

# Test cases
print(two_sum([2, 7, 11, 15], 9))  # [0, 1]
print(two_sum([3, 2, 4], 6))       # [1, 2]
print(two_sum([3, 3], 6))          # [0, 1]
```

**Key Insight**: Instead of checking all pairs (O(n²)), use hash map to check complements in O(1).

**Pattern**: Hash Map

**Similar Problems**: 3Sum, 4Sum, Two Sum II

#### 2. Best Time to Buy and Sell Stock

**Problem**: Maximize profit from one buy and one sell.

**Link**: [LeetCode #121](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

**Difficulty**: Easy

**Solution**:

```python
def max_profit(prices: list[int]) -> int:
    """
    Approach: Track minimum price and maximum profit
    
    Time: O(n)
    Space: O(1)
    """
    min_price = float('inf')
    max_profit = 0
    
    for price in prices:
        # Update minimum price seen so far
        min_price = min(min_price, price)
        
        # Calculate profit if we sell today
        profit = price - min_price
        
        # Update maximum profit
        max_profit = max(max_profit, profit)
    
    return max_profit

# Test cases
print(max_profit([7, 1, 5, 3, 6, 4]))  # 5 (buy at 1, sell at 6)
print(max_profit([7, 6, 4, 3, 1]))     # 0 (no profit possible)
```

**Key Insight**: We need to buy before we sell, so track the minimum price seen so far.

**Pattern**: Single Pass

**Similar Problems**: Best Time to Buy and Sell Stock II, III, IV

#### 3. Contains Duplicate

**Problem**: Check if array contains any duplicates.

**Link**: [LeetCode #217](https://leetcode.com/problems/contains-duplicate/)

**Difficulty**: Easy

**Solution**:

```python
def contains_duplicate(nums: list[int]) -> bool:
    """
    Approach: Use set to track seen numbers
    
    Time: O(n)
    Space: O(n)
    """
    seen = set()
    
    for num in nums:
        if num in seen:
            return True
        seen.add(num)
    
    return False

# One-liner alternative
def contains_duplicate_v2(nums: list[int]) -> bool:
    return len(nums) != len(set(nums))

# Test cases
print(contains_duplicate([1, 2, 3, 1]))     # True
print(contains_duplicate([1, 2, 3, 4]))     # False
print(contains_duplicate([1, 1, 1, 3, 3]))  # True
```

**Key Insight**: Set automatically handles uniqueness check in O(1) average time.

**Pattern**: Hash Set

**Similar Problems**: Contains Duplicate II, III

#### 4. Product of Array Except Self

**Problem**: Return array where output[i] is product of all elements except nums[i].

**Link**: [LeetCode #238](https://leetcode.com/problems/product-of-array-except-self/)

**Difficulty**: Medium

**Solution**:

```python
def product_except_self(nums: list[int]) -> list[int]:
    """
    Approach: Left and right product passes
    Without division, O(n) time, O(1) extra space
    
    Time: O(n)
    Space: O(1) - output array doesn't count
    """
    n = len(nums)
    result = [1] * n
    
    # Left pass: multiply all elements to the left
    left_product = 1
    for i in range(n):
        result[i] = left_product
        left_product *= nums[i]
    
    # Right pass: multiply all elements to the right
    right_product = 1
    for i in range(n - 1, -1, -1):
        result[i] *= right_product
        right_product *= nums[i]
    
    return result

# Test cases
print(product_except_self([1, 2, 3, 4]))     # [24, 12, 8, 6]
print(product_except_self([-1, 1, 0, -3, 3]))  # [0, 0, 9, 0, 0]
```

**Visualization**:
```
nums:    [1, 2, 3, 4]

After left pass:
result:  [1, 1, 2, 6]
         (1, 1*1, 1*2, 1*2*3)

After right pass:
result:  [24, 12, 8, 6]
         (1*24, 1*12, 2*4, 6*1)
```

**Key Insight**: Product except self = (product of left) × (product of right)

**Pattern**: Prefix/Suffix Product

**Similar Problems**: Range Product Queries

#### 5. Maximum Subarray

**Problem**: Find contiguous subarray with largest sum.

**Link**: [LeetCode #53](https://leetcode.com/problems/maximum-subarray/)

**Difficulty**: Medium

**Solution**:

```python
def max_subarray(nums: list[int]) -> int:
    """
    Approach: Kadane's Algorithm
    
    Time: O(n)
    Space: O(1)
    """
    max_sum = nums[0]
    current_sum = nums[0]
    
    for i in range(1, len(nums)):
        # Either extend existing subarray or start new
        current_sum = max(nums[i], current_sum + nums[i])
        
        # Update maximum
        max_sum = max(max_sum, current_sum)
    
    return max_sum

# Test cases
print(max_subarray([-2, 1, -3, 4, -1, 2, 1, -5, 4]))  # 6 ([4,-1,2,1])
print(max_subarray([1]))                               # 1
print(max_subarray([5, 4, -1, 7, 8]))                  # 23
```

**Visualization**:
```
nums:        [-2, 1, -3, 4, -1, 2, 1, -5, 4]
current_sum: [-2, 1, -2, 4,  3, 5, 6,  1, 5]
max_sum:     [-2, 1,  1, 4,  4, 5, 6,  6, 6]

Answer: 6 (subarray [4, -1, 2, 1])
```

**Key Insight**: At each position, decide whether to extend current subarray or start fresh.

**Pattern**: Kadane's Algorithm

**Similar Problems**: Maximum Product Subarray, Maximum Sum Circular Subarray
